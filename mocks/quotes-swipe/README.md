# quotes swipe

A draft of `/quotes`. It is not the live site. Nothing here is linked from `site/`. GitHub Pages only uploads `site/`.

From the repo root:

```
python3 -m http.server 8766
```

Open http://127.0.0.1:8766/mocks/quotes-swipe/

One quote sits in the homepage panel. A refresh always opens on today. The right arrow brings the next older quote in from the right. Off today, a faint left arrow goes back toward today. Today has no left arrow.
