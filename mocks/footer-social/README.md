# footer social pill

A draft. It is not the live site. Nothing here is linked from `site/`. GitHub Pages only uploads `site/`.

From the repo root:

```
python3 -m http.server 8766
```

Open http://127.0.0.1:8766/mocks/footer-social/

The page is snaps, with the top pill and a fixed social pill along the bottom. The icons are the old footer set: X, GitHub, Instagram, Threads, Spotify, LinkedIn, and email. They use the same pill chrome as the page tabs. Unselected icons are brand teal. A selected icon, if one is marked current, is a teal fill with white.

The pill is hidden on the homepage splash (`body.is-welcome`), so it does not sit on the centered intro.
